1. **🤖 AI 輔助與 Agent 相關工具**：包含 Hermes AI Agent、Codebase 3D 知識圖譜、Webwright、Multi-AI-Chat-Desktop、阿里 open-code-review、OpenAI Codex 外掛、Laminar Index、Ego-lite、AWS Kiro Crew、吳恩達團隊 OpenWorker、資安滲透 reverse-skill、倉頡 cangjie-skill 蒸餾引擎、OfficeCLI 等。
